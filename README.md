# Функционал банковского приложения

## Описание:

Модуль Masks: 
-функция get_mask_account, Маскирует номер банковского счета по формату '**XXXX'.
Принимает номер счета в виде числа, выводит маскированный номер счета.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/AbsoluteDude1337/homework
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять новые функции или задачи.
3. Работайте с необходимыми вам данными для проверки работы функции.
